# 视频裁剪工作台

Windows 个人桌面工具：本地视频播放、逐次精确裁剪、阿里云百炼 / 火山引擎原文字幕识别与 SRT 导出。代码目录为 `E:\study\video-subtitle-workbench`。

## 启动

在该目录打开 PowerShell：

```powershell
npm ci
npm run dev
```

本次已安装依赖。当前验证环境为 Node.js 18.20.4、npm 10.7.0、Electron 40.8.0、Vue 3、Vite 6。Node 18 已过维护期，后续建议升级 Node 后再更新工具链。当前 Electron 固定为兼容本机 Node 安装工具的版本。

Electron 主进程、preload、媒体处理、识别适配和开发启动脚本均已迁移为 TypeScript。`npm run dev` 通过 tsx 启动，esbuild 监听后台代码，生成 `.electron/main.cjs` 和 `.electron/preload.cjs` 后运行 Electron；这些 CJS 是忽略版本管理的运行产物，源代码位于 `.ts` 中。后台修改成功编译后自动重启，Vue 页面由 Vite 热更新。开发重启会清空当前片段与字幕列表，修改代码前应先导出需要保留的结果。

检查命令：`npm run type-check`，仅检查类型，不生成生产包。本次未运行生产 build。

FFmpeg 和 ffprobe 需要位于 PATH 中，也可启动前设置：

```powershell
$env:FFMPEG_DIR = 'D:\tools\ffmpeg-master-latest-win64-gpl\ffmpeg-master-latest-win64-gpl\bin'
npm run dev
```

项目 `.npmrc` 使用官方 Electron 下载源，覆盖本机用户配置中证书失效的旧淘宝镜像；未修改全局配置，也未关闭证书校验。本次受限执行环境运行 npm 偶发 `EPERM ... lstat C:\Users\wuxueqi`，正常用户权限下运行成功。遇到相同问题应核对执行环境的目录访问权限，不要以清空项目处理。

## 操作

1. 导入视频，在播放器中播放、暂停或拖动进度。
2. 输入开始和结束时间（秒数或 `HH:MM:SS.mmm`），或使用源视频的“设为当前”。
3. 选择一个尚不存在的 MP4 输出路径，开始裁剪。
4. 完成后在“已生成片段”列表中选择任意结果预览或打开其所在文件夹；预览结果时可返回当前源视频。
5. 可以继续裁剪下一个片段。成功结果按生成顺序追加，显示源视频、原始范围、实际时长和输出路径；重新导入视频也会保留此前结果。列表只在本次打开应用期间保留，关闭后不会自动恢复，但输出文件仍在磁盘上。

默认输出名为 `源文件名-片段1.mp4`。对于 `片段N.mp4` 或 `前缀-片段N.mp4`（N 为不带前导零的正整数，扩展名不区分大小写），成功后会在同一目录准备下一个编号，自动跳过已有文件和已登记的视频路径。下一次无需重复选择位置即可裁剪。重新打开输出选择器也会采用当前建议名。自定义名称如 `精彩开场.mp4` 保持不变，再次裁剪前需另选文件名。失败或取消不递增；每条历史记录的实际路径不受后续名称变化影响。

视频裁剪在本地处理。当前以 H.264 / AAC 重新编码，不依赖关键帧流复制。已有输出文件一律拒绝覆盖。裁剪时禁止关闭主窗口，最长单任务 30 分钟；裁剪暂不支持取消、队列和恢复。

## 配置识别服务

打开顶部“识别服务设置”，可只配置一家，后续再增加另一家。密钥留空表示保留此前保存的密钥，勾选“清除已保存凭证”后保存可清除对应服务商凭证。保存只验证字段和本地写入，实际账户权限、模型开通和额度需在首次识别时验证。不要把密钥写进项目文件或聊天。

| 服务商 | 本次接入 | 需要配置 |
| --- | --- | --- |
| 阿里云百炼 | `qwen3-asr-flash-filetrans`，DashScope 异步文件转写 | API Key、北京或新加坡地域；建议填写业务空间 ID，留空兼容通用域名 |
| 火山引擎 | 豆包录音文件识别极速版，`volc.bigasr.auc_turbo` | 新版豆包语音 API Key；也兼容旧版 App ID + Access Token，不能使用火山方舟大模型的 Key |

配置由 Electron 主进程使用 Windows 支持的 `safeStorage` 加密，保存到当前用户的应用配置目录 `speech-settings.bin`，不保存在代码目录。读取接口只返回配置状态及非秘密选项，不返回密钥；页面输入的密钥在保存成功或收起设置后清空。系统加密不可用时不降级为明文保存。加密文件与 Windows 用户环境关联，不应直接复制到其他用户环境使用。

官方接入说明：[阿里云 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)、[Qwen 文件转写 API](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[火山引擎极速版](https://docs.volcengine.com/docs/doubao-voice/large-model-recording-file-lite-recognition-api?lang=en)。

## 生成原文字幕与导出

1. 先裁剪出片段，在该条记录中选择“阿里云百炼”或“火山引擎”，选择音频语言或自动识别。
2. 点击“生成原文字幕”。本地从该裁剪结果提取 16kHz、单声道 WAV，只上传片段音频，不上传整段源视频或视频画面。当前限制为不超过 2 小时、提取后音频不超过 100MB，适用于本项目短片段使用场景。
3. 每条片段独立显示提取、上传、识别和完成状态，最多同时处理两个识别任务，可停止本地等待。停止不保证撤销已经提交的云端工作，也不保证免除费用；火山同步请求重试可能再次计费。
4. 完成后展示只读原文字幕及句级时间轴。时间基准是裁剪片段的 0 秒，保留开头静音，不强行把第一句话移到 0 秒，也不叠加源视频的裁剪起点。
5. 导出 UTF-8（带 BOM）、CRLF 换行的原文 `.srt`，可自行选择路径；已有文件不覆盖。没有识别到说话内容时不给出伪造字幕，无音轨片段不能识别。

重新识别失败或停止时会保留上一份有效字幕，仍可查看和导出。阿里云提交后若仅查询或下载中断，本次打开期间、同一片段 / 语言 / 凭证下重试会继续查询原任务，不重复提交；更换服务商、凭证或语言可能产生新任务。每次识别本地最多等待 20 分钟。云端费用和最终识别质量以服务商及真实素材为准。

识别失败会显示具体阶段（申请上传凭证、OSS 上传、提交识别、查询任务、下载结果或解析字幕）、目标主机和诊断码，例如 `ENOTFOUND`、`CERT_HAS_EXPIRED`、`REQUEST_TIMEOUT`、`HTTP_401`。不显示密钥、请求内容、完整 URL 或签名参数。提示还会区分尚未提交、提交结果未确认、已提交和已完成；“提交未确认”不能视为云端已有任务。可以将这段诊断文字用于排查。

阿里云当前采用官方临时音频上传通道，文件约 48 小时后由平台清理，本工具不执行云端主动删除；本地提取文件在任务结束时清理。该通道用于本轮个人低频验证，不作为生产或高并发存储方案。正式发布、长期运行时应改用自有 OSS 及明确的清理策略，参考[官方临时上传说明](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)。火山引擎通过 Base64 随请求上传音频，无需另外配置对象存储。

## 当前限制

开发启动使用本机 Vite 服务，不是安装包，尚未配置生产打包。播放器支持范围由 Electron 的解码器决定，FFmpeg 可识别的视频不保证都能直接播放；界面给出无法播放提示，可尝试输出 MP4 后预览。HDR、旋转元数据、多音轨、可变帧率等复杂媒体尚未专项验证；仅选取首个视频轨和可选首个音轨。视频输出发布使用同目录临时文件与硬链接避免覆盖，因此需输出文件系统支持硬链接（常见 NTFS 支持，部分移动存储或网络盘不支持，会明确报错）。当前片段、字幕和远端任务 ID 只在本次打开期间保留，关闭后不能恢复，导出的视频和 SRT 文件不受影响；凭证配置会加密保存。尚不支持网站下载、翻译、字幕编辑、项目保存恢复或多个待处理片段的编辑管理。
