# 切片字幕机

Windows 个人桌面工具：本地视频播放、逐次精确裁剪、阿里云百炼 / 火山引擎原文字幕识别、字幕翻译，以及原文 / 译文 / 双语 SRT 导出。代码目录为 `E:\study\video-subtitle-workbench`。

## 启动

在该目录打开 PowerShell：

```powershell
npm ci
npm run dev
```

本次已安装依赖。当前验证环境为 Node.js 18.20.4、npm 10.7.0、Electron 40.8.0、Vue 3、Vite 6。Node 18 已过维护期，后续建议升级 Node 后再更新工具链。当前 Electron 固定为兼容本机 Node 安装工具的版本。

Electron 主进程、preload、媒体处理、识别适配和开发启动脚本均已迁移为 TypeScript。`npm run dev` 通过 tsx 启动，esbuild 监听后台代码，生成 `.electron/main.cjs` 和 `.electron/preload.cjs` 后运行 Electron；这些 CJS 是忽略版本管理的运行产物，源代码位于 `.ts` 中。后台修改成功编译后自动重启，Vue 页面由 Vite 热更新。开发重启会清空当前片段与字幕列表，修改代码前应先导出需要保留的结果。

检查命令：`npm run type-check`，仅检查类型，不生成生产包。日常检查不追加 build；下述打包命令按明确的打包需求执行生产编译。

## Windows 打包：release1.0

当前应用版本为 `1.0.0`，提供 Windows x64 安装包，使用与本机 Node 18 兼容的 `electron-builder 24.13.3`（已锁定版本）。

```powershell
npm ci
npm run package:dir
npm run package:win
```

- `package:dir`：先做类型检查，再编译生产页面与后台，生成 `release1.0/win-unpacked/切片字幕机.exe`。整个 `win-unpacked` 文件夹可以直接运行，不能只复制其中的 exe。
- `package:win`：执行同样的检查与生产编译，生成 `release1.0/切片字幕机-1.0.0.exe`，这是支持选择安装目录的当前用户 NSIS 安装程序，不会自动发布到 GitHub。
- 两个命令都从 `FFMPEG_DIR` 或 PATH 定位 FFmpeg 发行包，要求 bin 中有 `ffmpeg.exe`、`ffprobe.exe`，上级目录有 `LICENSE.txt`。会复制这两个程序、依赖 DLL 及许可信息到 `.packaging/ffmpeg`，最终随包放入 `resources/ffmpeg`。未配置自定义路径时，本次使用本机已有发行包。
- 打包默认复用 `node_modules/electron/dist` 的 Electron；安装依赖和首次获取 NSIS 等工具需要可用网络。`.electron`、`dist`、`.packaging` 和 `release1.0` 都是生成目录，不提交到 Git。

安装版直接加载本地生产页面，不需要 Vite、Node.js 或系统 FFmpeg；识别和翻译仍需联网并配置相应服务凭证。`FFMPEG_DIR` 在运行时仍可显式覆盖随包程序，用于排查或替换版本。

应用显示名称为“切片字幕机”，沿用现有内部应用标识和默认用户配置目录 `%APPDATA%/video-subtitle-workbench`，开发版与安装版保持一致，改名后可继续读取已保存的服务凭证，不把凭证或用户媒体打入安装包。覆盖安装和卸载不主动清除该目录。验证时可用 `--user-data-dir=绝对路径` 指定隔离目录。安装包当前未做代码签名；安装包和应用均只在本地生成。

产品图标采用“胶片＋文字气泡”的无底板透明版本，由内置 ImageGen 生成；保留亮蓝胶片框、播放符号、白色字幕气泡及深蓝描边和字幕条，外部背景、胶片孔位及画面留白均透明。原图为 `public/app-icon.png`，Windows 图标为 `public/app-icon.ico`，包含 16、20、24、32、40、48、64、128、256px 尺寸。生成提示词的核心要求为：保持胶片和字幕气泡造型，只移除背景底板，保留气泡内部白色及两条字幕线，几何轮廓清晰，适合小尺寸，无文字、无水印。

顶部标识和浏览器页签、Electron 窗口、Windows 程序与快捷方式、安装和卸载程序均使用该图标。Vite 会将 `public` 中的图标复制到生产页面目录；Windows 打包开启 EXE 资源编辑以嵌入图标，沿用现有未签名设置。已生成的旧安装包需重新打包后才会包含新图标。

## 操作

1. 导入视频，在播放器中播放、暂停或拖动进度。
2. 输入开始和结束时间（秒数或 `HH:MM:SS.mmm`），或使用源视频的“设为当前”。
3. 选择一个尚不存在的 MP4 输出路径，开始裁剪。
4. 完成后在“已生成片段”列表中选择任意结果预览或打开其所在文件夹；预览结果时可返回当前源视频。
5. 可以继续裁剪下一个片段。成功结果按生成顺序追加，显示源视频、原始范围、实际时长和输出路径；重新导入视频也会保留此前结果。列表只在本次打开应用期间保留，关闭后不会自动恢复，但输出文件仍在磁盘上。

默认输出名为 `源文件名-片段1.mp4`。对于 `片段N.mp4` 或 `前缀-片段N.mp4`（N 为不带前导零的正整数，扩展名不区分大小写），成功后会在同一目录准备下一个编号，自动跳过已有文件和已登记的视频路径。下一次无需重复选择位置即可裁剪。重新打开输出选择器也会采用当前建议名。自定义名称如 `精彩开场.mp4` 保持不变，再次裁剪前需另选文件名。失败或取消不递增；每条历史记录的实际路径不受后续名称变化影响。

视频裁剪在本地处理。当前以 H.264 / AAC 重新编码，不依赖关键帧流复制。已有输出文件一律拒绝覆盖。裁剪时禁止关闭主窗口，最长单任务 30 分钟；裁剪暂不支持取消、队列和恢复。

## 配置识别服务

打开顶部“服务设置”，可只配置需要使用的服务。识别与翻译配置分别保存，保存成功后自动收起设置区域，保存失败时保留面板和输入以便重试。已保存的 API Key 和 Access Token 显示固定八个圆点占位，与真实凭证长度无关；输入新值可替换，不输入则保留已保存的凭证。阿里云识别和翻译的 API Key 右侧提供“清空凭证”按钮，二次确认后立即清空对应凭证，其他未保存的表单草稿保持不变；火山服务仍可勾选“清除已保存凭证”后保存清除。保存只验证字段和本地写入，实际账户权限、模型开通和额度需在使用服务时验证。不要把密钥写进项目文件或聊天。

| 服务商 | 本次接入 | 需要配置 |
| --- | --- | --- |
| 阿里云百炼 | `qwen3-asr-flash-filetrans`，DashScope 异步文件转写 | API Key、北京或新加坡地域；建议填写业务空间 ID，留空兼容通用域名 |
| 火山引擎 | 豆包录音文件识别极速版，`volc.bigasr.auc_turbo` | 新版豆包语音 API Key；也兼容旧版 App ID + Access Token，不能使用火山方舟大模型的 Key |

## 生成原文字幕与导出

1. 导入视频后，右侧默认打开“识别原文字幕”。选择“阿里云百炼”或“火山引擎”、音频语言或自动识别，点击“开始识别整段视频”，无需裁剪或选择视频输出位置。未配置服务时会打开设置并保留选项；保存后需再次点击开始，不会自动提交。
2. 需要片段时切换到“裁剪视频”，设置范围并保存 MP4，再在该片段记录中点击“生成原文字幕”。两种方式均在本地提取 16kHz、单声道 WAV，只上传待识别视频的音频，不上传视频画面。当前限制为不超过 2 小时、提取后音频不超过 100MB；超出限制可先裁剪缩短范围。
3. “视频与字幕任务”用“完整视频 / 裁剪片段”标签区分来源，独立显示提取、上传、识别和完成状态。最多同时处理两个识别任务；同一整段视频已加入列表后，右侧显示“查看识别任务”，重试或重新识别在任务卡中操作。导入下一个视频不会清空已有任务。可停止本地等待，但停止不保证撤销已提交的云端工作或免除费用；火山同步请求重试可能再次计费。
4. 完成后展示只读原文字幕及时间轴。整段识别以源视频开头为基准，裁剪识别以对应片段开头为基准；保留开头静音，不强行把第一句话移到 0 秒，也不叠加源视频的裁剪起点。
5. 导出 UTF-8（带 BOM）、CRLF 换行的原文 `.srt`，此时可自行选择字幕保存路径；已有文件不覆盖。没有识别到说话内容时不给出伪造字幕，无音轨视频不能识别。

阿里云优先使用已按句末标点分好的句级时间轴；一条返回仍含多句话时，再利用字词时间戳细分。缺少字词时间戳或无法准确细分时，只要云端原段落时间有效，就直接保留整段字幕，正常展示、导出和翻译。拆分后允许字幕时间重叠，不强行调整时间。句内个别字词起止时间相同不会阻止有效单句显示。零时长整句、无效时间或无法展示的条目单独列入“待校对”，保留原文、云端时间和原始条目，并显示原因；其他有效字幕仍可导出、翻译，待校对内容不混入本次有效字幕。仅开发环境（未打包运行）会将下载的阿里云完整原始结果另存到应用数据目录的 `asr-debug` 文件夹，并在任务提示中显示保存结果及完整路径；打包后的可运行目录和安装版不保存此调试文件，也不显示相关保存提示或路径。

待校对条目可直接修改开始、结束时间，支持秒数或 `HH:MM:SS.mmm`。点击“确认加入字幕”时校验时间范围，结束须晚于开始至少 1 毫秒且不超出对应视频时长；确认后按时间排序加入有效字幕，后续原文 SRT 导出和重新加载的翻译来源均包含该条。点击“废弃”会将该条标为已废弃，不加入有效字幕。已加入、已废弃条目均可在“已处理”中查看，原始数据保留。识别运行期间暂停校对操作。

校对加入后，已经加载的翻译面板会提示原文已更新；点击“加载当前字幕”后才可开始新的翻译。正在进行或已完成的翻译保留此前的字幕快照。校对记录与任务一样在本次打开期间保留，导出 SRT 可保存修正后的有效字幕；重新识别成功会更新本轮字幕与校对记录。

重新识别失败或停止时会保留上一份有效字幕，仍可查看和导出。阿里云提交后若仅查询或下载中断，本次打开期间、同一视频或片段 / 语言 / 凭证 / 识别配置下重试会继续查询原任务，不重复提交；更换服务商、凭证、语言或识别配置可能产生新任务。每次识别本地最多等待 20 分钟。云端费用和最终识别质量以服务商及真实素材为准。

识别失败会显示具体阶段（申请上传凭证、OSS 上传、提交识别、查询任务、下载结果或解析字幕）、目标主机和诊断码，例如 `ENOTFOUND`、`CERT_HAS_EXPIRED`、`REQUEST_TIMEOUT`、`HTTP_401`。不显示密钥、请求内容、完整 URL 或签名参数。提示还会区分尚未提交、提交结果未确认、已提交和已完成；“提交未确认”不能视为云端已有任务。可以将这段诊断文字用于排查。

阿里云当前采用官方临时音频上传通道，文件约 48 小时后由平台清理，本工具不执行云端主动删除；本地提取文件在任务结束时清理。该通道用于本轮个人低频验证，不作为生产或高并发存储方案。正式发布、长期运行时应改用自有 OSS 及明确的清理策略，参考[官方临时上传说明](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)。火山引擎通过 Base64 随请求上传音频，无需另外配置对象存储。

## 字幕翻译

翻译入口独立于视频，可直接处理外部校对后的 SRT，无需重新识别音频或裁剪视频。

1. 在顶部打开“字幕翻译”，选择“当前识别字幕”或“导入 SRT 文件”。任务卡中的“翻译字幕”按钮会自动加载该视频或片段当前识别结果。
2. 当前识别字幕可选择已有字幕的完整视频或裁剪片段；“加载当前字幕”可以重新获取其最新内容。导入来源通过本地文件选择器读取 UTF-8 SRT（兼容 BOM、CRLF、多行文字及逗号/点号毫秒分隔），不支持 GBK 等旧编码，请先另存为 UTF-8。
3. 确认来源名称、字幕数量、时间范围，可展开只读原文预览。空文件、错误编号、无效时间、空文字等会定位到具体条目；不静默跳过。当前限制为文件 5MB 内、最多 2000 条、每条 8000 字符以内。
4. 配置翻译服务、模型与目标语言后开始。程序按条目翻译，最多两个请求并发，只发送字幕文字；时间轴、顺序和条目对应保留，不重新上传音频、不自动拆分或调轴。
5. 任务运行时锁定来源、服务商和目标语言。来源内容在加载时保存独立快照，重新识别原片段或外部修改原文件不会混入正在翻译的任务。需要新内容时主动重新加载或导入。
6. 失败或停止时保留已完成译文，点击“重试未完成部分”只重试未完成条目。修正凭证后可继续重试；更换服务商、目标语言、来源或模型时创建新任务，不混用先前结果。鉴权、模型参数或限流等 HTTP 4xx 错误会停止继续派发请求。单条请求最多等待 120 秒，单任务最多运行 30 分钟。
7. 全部完成后可以导出“译文 SRT”与“双语 SRT”。双语默认原文在上、译文在下，时间轴与原文一致。输出为 UTF-8 BOM、CRLF，默认新文件名带语言代码；不会覆盖导入的原文或已有文件。

## 验证记录

- `npm run type-check` 通过，涵盖 Vue、主进程、preload 和启动脚本；未运行 build。
- 实际启动 Electron，验证源视频播放、暂停、跳转到 2 秒、“设为当前”、无效范围提示、选择输出、真实裁剪、结果播放。自动化替代文件对话框的选择返回值，未绕过业务处理；原生文件选择、输出位置选择和打开所在文件夹由用户反馈已手动验证。
- 确认 renderer 中 `require` 不可用，通过 preload 暴露限定、类型化接口；媒体 URL 只支持后台已登记文件，并支持 HTTP Range 式分段读取以正确拖动进度。
- 中文、空格、`&` 路径完成实际裁剪；使用独立子进程参数数组，无 shell 拼接。
- 合成 6 秒、30 fps、关键帧间隔 5 秒视频，裁剪 `1.237–4.583` 秒。目标 3.346 秒，输出 101 帧 / 3.366667 秒，时长差 20.667 ms，小于一帧 33.333 ms。

## 当前限制

开发启动使用 Vite，安装版使用本地页面，两者共享默认用户配置目录。播放器支持范围由 Electron 的解码器决定，FFmpeg 可识别的视频不保证都能直接播放；界面给出无法播放提示，可尝试输出 MP4 后预览。HDR、旋转元数据、多音轨、可变帧率等复杂媒体尚未专项验证；仅选取首个视频轨和可选首个音轨。视频输出发布使用同目录临时文件与硬链接避免覆盖，因此需输出文件系统支持硬链接（常见 NTFS 支持，部分移动存储或网络盘不支持，会明确报错）。当前片段、字幕、翻译任务和远端任务 ID 只在本次打开期间保留，关闭后不能恢复，导出的视频和 SRT 文件不受影响；凭证配置会加密保存。尚不支持网站下载、视频字幕同步预览、字幕编辑、项目保存恢复或多个待处理片段的编辑管理。
